# Abimra Studio: About page handoff for Claude Code

## What to do
1. **Unzip** into your theme repository root as `abimra-handoff-about/`, and add `abimra-handoff-about/**` to `.shopifyignore`.
2. **Commit your theme first:** `git add -A && git commit -m "Before About page"`.
3. **Open Claude Code** in the theme repository and send:
   ```
   Read abimra-handoff-about/CLAUDE_CODE_PROMPT.md first, then abimra-handoff-about/SPEC.md.
   Open abimra-handoff-about/reference/about-design.html to see the target, and look at the screenshots in abimra-handoff-about/reference/screens/.
   The files to install are in abimra-handoff-about/theme-files/.
   Start with step 1 (inspect the theme) and send me your plan. Don't edit anything until I approve it.
   ```
4. **Review its plan,** then approve.
5. **In the Shopify admin,** go to Online Store > Pages, open your About page (or create it), and choose **page.about** under Theme template.
6. **In the theme editor, fill in the placeholders:** the story (year, town, founder's name and why you started), the signature, your email (link: `mailto:…`) and your Instagram handle. Anything still in [square brackets] shows in red until you replace it.
7. **Add the story photo:** 5:4 landscape, 2000 × 1600 px.
